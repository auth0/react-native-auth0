📋 Overview

This PR enables passwordless authentication using passkeys on the React Native web platform. The flow involves three main participants:

  1. React Native Web App - The application UI and user interaction layer
  2. react-native-auth0 SDK - The abstraction layer providing unified API across platforms
  3. Browser WebAuthn API - Native browser capability for passkey management
  4. Auth0 Backend - Authentication server handling challenge generation and token exchange

🔑 Key Implementation Details

Platform-Specific Behavior

Native (iOS/Android): authResponse must be a JSON string (serialized credential). The native bridge handles serialization.

Web: authResponse can be either:

  • Raw PublicKeyCredential (primary path) - App passes the credential object directly from navigator.credentials
  • JSON string (fallback) - For parity with native, spa-js _requestTokenForPasskey is called

Detection: typeof authResponse === 'string' at WebAuth0Client.ts:414

Error Code Mapping Examples

Source Error Code Normalized Type Scenario
passkey_not_supported PASSKEY_NOT_AVAILABLE Browser lacks WebAuthn support
passkey_challenge_error PASSKEY_CHALLENGE_FAILED Auth0 challenge request failed
invalid_grant PASSKEY_EXCHANGE_FAILED Token exchange rejected by Auth0
mfa_required PASSKEY_MFA_REQUIRED Additional MFA step needed
NotAllowedError (DOMException) PASSKEY_CANCELLED User dismissed WebAuthn prompt
SecurityError (DOMException) PASSKEY_NOT_AVAILABLE HTTPS required or RP ID mismatch
InvalidParameter PASSKEY_INVALID_PARAMETER Malformed JSON authResponse

Security Requirements

  • HTTPS Required: WebAuthn APIs only work in secure contexts (HTTPS or localhost for dev)
  • User Gesture: navigator.credentials.create() / .get() must be called from a click handler
  • Same Origin: RP ID must match the origin serving the app
  • DPoP Enabled: Default token type is DPoP for enhanced security

🚀 Usage Example (Complete Flow)

import { useAuth0, PasskeyError } from 'react-native-auth0';

function PasskeySignupButton() {
  const { passkeySignupChallenge, getTokenByPasskey } = useAuth0();

  const handleSignup = async () => {
    try {
      // Step 1: Request challenge from Auth0 (via SDK)
      const challenge = await passkeySignupChallenge({
        email: 'user@example.com',
        realm: 'Username-Password-Authentication',
      });

      // Step 2: Create passkey using browser WebAuthn API
      // (App-driven, NOT wrapped by SDK)
      const credential = (await navigator.credentials.create({
        publicKey: challenge.authParamsPublicKey as PublicKeyCredentialCreationOptions,
      })) as PublicKeyCredential;

      // Step 3: Exchange credential for tokens (via SDK)
      const credentials = await getTokenByPasskey({
        authSession: challenge.authSession,
        authResponse: credential, // Raw PublicKeyCredential
        realm: 'Username-Password-Authentication',
      });

      console.log('Signed up with passkey');
      // credentials.accessToken, credentials.idToken available
    } catch (error) {
      // App-level error handling (SDK throws PasskeyError)
      if (error instanceof PasskeyError) {
        // SDK has already normalized error.type across platforms
        console.error('Passkey operation failed:', error.type);
      }
    }
  };

  return <button onClick={handleSignup}>Sign Up with Passkey</button>;
}
