    Platform-agnostic error code constants for My Account API operations.

    Use these constants for type-safe error handling when enrolling, confirming, or managing authentication methods. Each constant corresponds to a specific error type in the MyAccountError.type property.

    Type Declaration

    • ReadonlyUNAUTHORIZED: "UNAUTHORIZED"

      The access token is missing, expired, or lacks the required scopes

    • ReadonlyINVALID_REQUEST: "INVALID_REQUEST"

      The request was rejected as malformed or invalid by the API

    • ReadonlyENROLLMENT_FAILED: "ENROLLMENT_FAILED"

      Enrolling the authentication method failed

    • ReadonlyVERIFICATION_FAILED: "VERIFICATION_FAILED"

      Confirming or verifying the enrollment failed

    • ReadonlyNOT_FOUND: "NOT_FOUND"

      The requested authentication method does not exist

    • ReadonlyCONFLICT: "CONFLICT"

      The authentication method already exists or conflicts with an existing one

    • ReadonlyTOO_MANY_REQUESTS: "TOO_MANY_REQUESTS"

      Too many requests - rate limited

    • ReadonlyMY_ACCOUNT_ERROR: "MY_ACCOUNT_ERROR"

      Generic My Account API error

    • ReadonlyUNKNOWN_MY_ACCOUNT_ERROR: "UNKNOWN_MY_ACCOUNT_ERROR"

      Unknown or uncategorized My Account error

    Remarks

    The My Account API reports failures as RFC 7807 type URIs (e.g. "https://auth0.com/api-errors/A0E-401-0001"). Those URIs are normalized to these codes so error handling matches every other error class in the SDK. The original URI remains available on MyAccountError.typeUri.

    Example

    import { MyAccountError, MyAccountErrorCodes } from 'react-native-auth0';

    try {
      await myAccount.enrollPhone({ accessToken, phoneNumber: '+1234567890' });
    } catch (e) {
      if (e instanceof MyAccountError) {
        switch (e.type) {
          case MyAccountErrorCodes.UNAUTHORIZED:
            // Access token expired or missing the required scopes
            break;
          case MyAccountErrorCodes.ENROLLMENT_FAILED:
            // The factor could not be enrolled
            break;
        }
      }
    }
