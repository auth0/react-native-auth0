    Interface NetworkingOptions

    Configuration for the native networking client used by Auth0.Android. Mirrors DefaultClient.Builder from the Auth0.Android SDK.

    Remarks

    The timeout and header fields are Android only and have no effect on iOS or web. enableLogging is honored on iOS as well (it maps to Auth0.swift's .logging(enabled:)).

    Example

    networkingOptions: {
      connectTimeout: 30,
      readTimeout: 30,
      defaultHeaders: { 'X-App-Version': '1.2.3' }
    }
    interface NetworkingOptions {

    OptionalenableLogging

    enableLogging?: boolean

    Enables verbose HTTP request/response logging for the native SDKs.

    Remarks

    On Android this maps to the OkHttp logging interceptor and writes full request and response bodies to Logcat — including access, refresh, and ID tokens in plaintext — so it is debug-only (ignored on release builds) and must never be enabled in production.

    On iOS this maps to Auth0.swift's .logging(enabled:), which traces requests and responses to the unified logging system (OSLog) with access, refresh, and ID tokens redacted. It has no build-type gate, so still enable it only while debugging.

    Default

    false
